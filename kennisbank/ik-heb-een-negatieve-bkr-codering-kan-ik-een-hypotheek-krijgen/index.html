Ik heb een negatieve BKR-codering. Kan ik een hypotheek krijgen?

Bekijk in de kennisbank →

Veel mensen staan met een of meer kredieten geregistreerd bij het BKR. Een hypotheek afsluiten wordt lastig als er sprake is van een negatieve BKR-registratie.

Een A (achterstandsmelding) betekent dat je meerdere termijnen achterloopt met het terugbetalen van je krediet. Je krijgt hierover eerst een vooraankondiging van de kredietverstrekker. Hier zullen banken over kunnen vallen bij het verstrekken van een hypotheek.

Een H (herstelmelding) betekent dat je de betalingsachterstand hebt ingelopen, maar dat het krediet nog doorloopt. Los je het krediet daarna helemaal af, dan zie je alleen nog dat het krediet is beëindigd.

Je eigen registratie kun je inzien via mijnkredietregistratie.nl van het BKR.

Bij een registratie kunnen ook nog bijzonderheden met een cijfercode staan. Daaraan kan worden afgelezen wat de situatie is of was.

De volgende codes worden gebruikt:

  • Code 1, betalingsregeling: je hebt een achterstand en hebt afspraken gemaakt met de kredietaanbieder om die in delen terug te betalen.
  • Code 2, opeising: de kredietaanbieder eist het gehele bedrag in één keer op.
  • Code 3, afboeking: de kredietaanbieder heeft een bedrag afgeboekt dat hij niet meer verwacht terug te krijgen, of heeft € 250 of meer van je betalingsachterstand kwijtgescholden. Bij een kwijtschelding wordt ook een einddatum geregistreerd.
  • Code 4, onbereikbaar: de kredietaanbieder heeft contact met je gezocht, maar je bent al langere tijd onbereikbaar.
  • Code 5, preventieve betalingsregeling: je hebt een achterstand op je hypotheek en maakt uit voorzorg afspraken om die terug te betalen. Na betaling wordt de vermelding verwijderd.

De aard van de registratie zal de geldverstrekker ook zwaar mee laten wegen. Kredieten worden geregistreerd vanaf € 250 als ze langer dan één maand lopen; bij een kwijtschelding speelt de grens van € 250 ook een rol.

Vijf jaar na de einddatum van de lening verdwijnen de registraties.
