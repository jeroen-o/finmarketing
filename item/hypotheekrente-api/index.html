Hypotheekrente API en hypotheek-webservices

Actuele hypotheekrentetarieven van banken, verzekeraars en regiepartijen in één API, plus webservices voor maximale hypotheek, NHG, LTV, LTI, inkomen en meer. Voor ontwikkelaars die zelf een hypotheektool, websitetool of app bouwen.

Wat zit erin?

  • Hypotheekrente API: altijd de actuele hypotheekrentetarieven van verschillende aanbieders
  • Maximale hypotheek API
  • Bruto netto API
  • NHG API
  • Belasting API
  • Maximum LTV API en maximum LTI API
  • Inkomen bepalen API en ondernemersinkomen bepalen API
  • Rente top 5 API
  • Annuïteiten API en lineaire API
  • Postcode API
  • HDN import API, en meer in de API-catalogus
